# Week 4. Bitwise Operations. Bit Masks.

---

## Problem 1 (Bit in a Number)

Create a program that reads from standard input non-negative integers `n` and `s` and prints to standard output the `s`-th bit of the number `n`.

---

## Problem 2 (Changing Bits)

Create a program that reads from standard input non-negative integers `n`, `r`, and `s`, changes the `r`-th bit of the number `n` to 1, changes the `s`-th bit of the number `n` to 0, and prints the modified number `n` to standard output.

---

## Problem 3 (Even Number)

Create a program that reads from standard input a non-negative integer and checks whether it is even using bitwise operations.

---

## Problem 4 (Bit Clear)

Create a program that reads from standard input non-negative integers `n` and `r` and sets the `r`-th bit to 0, printing `n` to standard output.

---

## Problem 5 (Bit Set)

Create a program that reads from standard input non-negative integers `n` and `r` and sets the `r`-th bit to 1, printing `n` to standard output.

---

## Problem 6 (Bit Flip)

Create a program that reads from standard input non-negative integers `n` and `r` and inverts the `r`-th bit of the number `n`, printing `n` to standard output.

---

## Problem 7 (Swap Variables)

Create a program that reads from standard input two non-negative integers `x` and `y` and swaps their values using the bitwise `XOR` operation.

---

## Problem 8 (Raising to a Power)

Create a program that reads from standard input a non-negative integer `n` and prints to standard output the result of the number 2 raised to the power `n`.

---

## Problem 9 (Power of 2)

Create a program that reads from standard input a non-negative integer `n` and checks whether the number `n` is a power of 2.

---

## Problem 10 (Power of 4)

Create a program that reads from standard input a positive number `n` and checks whether the number `n` is a power of 4.

> Every power of the number 4 in binary representation has exactly 1 bit with value 1, and that bit is at an even position.

---

## Problem 11 (Counting Bit 1)

Create a program that reads a character from standard input and prints to standard output how many bits in the decimal representation of the character have value 1.

---

## Problem 12 (Counting Bit 0)

Create a program that reads a character from standard input and prints to standard output how many bits in the decimal representation of the character have value 0.

---

## Problem 13 (Hamming Distance)

Create a program that reads two characters from standard input and prints to standard output the Hamming distance between the two decimal representations of the two characters. The Hamming distance shows in how many positions the bits in the two decimal representations differ.
